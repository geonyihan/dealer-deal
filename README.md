# 무료응모 헌터 (deal-hunter)

구매 없이 참여하는 **무료 응모·경품** 중 현금 가치 1,000원 이상(커피·편의점 기프티콘 포함)만 모아 보여주는 개인용 정적 웹앱.

- `index.html` — 앱 전체(HTML/CSS/JS 한 파일, 빌드 없음)
- `data/events.json` — 응모 데이터. 모든 항목은 공식 페이지를 직접 열어 마감 전임을 확인한 것만 수록
- `images/` — 이벤트별 경품 썸네일(`{id}.jpg`, 320×320), 브랜드 아이콘(`brands/`), 앱 캐릭터(`avatar.png`)
- GitHub Pages 서브패스(`/dealer-deal/`)와 로컬 루트에서 모두 동작하도록 모든 경로는 `./` 상대경로 사용

## 화면 구성

에디토리얼 1열 리스트(본문 최대 560px, 얇은 구분선). 박스 카드 대신 신문 지면 같은 목록형.

- **헤더**: 원형 캐릭터 아이콘 + 타이틀 + 회색 부제, 우측 다크모드 토글
- **툴바**: 미니멀 검색창, 필터 칩(전체 / 인스타 / 공식몰·폼 / 사전예약 / 완료 숨기기), 정렬 칩(마감임박순 / 최신순)
- **섹션 헤더**: `진행 중인 혜택 (28)` + 우측 `11. 18. 확인` + 2px 검정 하단선
- **행**: 브랜드 아이콘·브랜드명 → 굵은 제목 → 테라코타 메타(`추첨 · 11월 19일 마감 · D-1`), 우측 84×84 둥근 썸네일 / 참여 방법 1~2줄 / `참여 조건 +` 토글 / `공식 페이지에서 참여 ↗` + `응모 완료` 토글
- 응모 완료 상태는 localStorage에 저장되고 행이 흐려지며, `완료 숨기기`로 감출 수 있음
- 다크/라이트 모드(저장 + 시스템 설정 기본값)

## 데이터 갱신

`data/events.json`의 `events` 배열에 항목을 추가/삭제하고 `updated`, `updated_label`을 고치면 됩니다.
새 항목에는 `images/{id}.jpg`(320×320, 84px 썸네일용)와 `icon`(브랜드 아이콘 경로)을 함께 넣습니다.

```json
{
  "id": "고유-id",
  "brand": "브랜드",
  "title": "이벤트명",
  "value_note": "경품과 대략적 가치",
  "category": "insta | official | form | prereg",
  "deadline": "YYYY-MM-DD 또는 상시",
  "start": "YYYY-MM-DD",
  "summary": "1~2줄 참여 방법",
  "conditions": "세부 조건·발표일",
  "url": "공식 이벤트 URL",
  "image": "./images/고유-id.jpg",
  "icon": "./images/brands/도메인.png",
  "verified_at": "YYYY-MM-DD"
}
```

썸네일은 ① 공식 페이지 `og:image` → ② 공용 경품(커피·상품권·포인트 등)은 깔끔한 상품 이미지를 재사용하는 순서로 채웠습니다. 브랜드 아이콘은 Google Favicon(64px) 또는 이니셜 원형 아이콘입니다.

개인정보(이름·전화번호·주소 등)는 코드와 데이터에 넣지 않습니다.
